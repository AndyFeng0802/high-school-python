## 第 1 關：任務廣播

[查看程式 01_broadcast.py](01_broadcast.py)

```python
print("任務代號：星光")
print("目的地：月球")
print("準備出發！")
```

每行 `print()` 顯示一行文字，執行順序就是寫下的順序。

## 第 2 關：換我當導演

[查看程式 02_director.py](02_director.py)

```python
# 我的太空旅行
print("交通工具：太空船")
print("目的地：火星")
```

只需要更換引號內的內容，保留外面的語法符號。第一行是註解，不會輸出。

## 第 3 關：除錯偵探

[查看程式 03_debug.py](03_debug.py) 可一次看見修正後的三行輸出。

```python
print("找到寶箱！")
print("獲得地圖")
print("任務完成")
```

- A：在驚嘆號後補上半形 `"`，讓字串完整。
- B：將 `（`、`）` 改成半形 `(`、`)`。引號內的中文仍可保留。
- C：在字串結尾後補上 `)`，讓括號配對。

常見誤區：只改一邊的全形括號，或把正確的中文內容也刪掉。要修的是程式符號。

## 第 4 關：四格文字故事

[查看程式 04_story.py](04_story.py)

```python
# 主題：迷糊的太空導航
print("今天我搭上太空船。")
print("導航突然說它想放假。")
print("我拿出紙本地圖。")
print("原來目的地就在隔壁！")
```

這只是一個範例。故事可以不同，只要四行有順序、能執行、有一行註解就完成。

## 課內作品：我的程式名片

[查看程式 05_my_card.py](05_my_card.py)

```python
# 我的第一張程式名片
print("=== 我的程式名片 ===")
print("暱稱：星際飯糰")
print("興趣：聽音樂")
print("招牌技能：把問題拆小")
print("今天的任務：完成第一支程式")
```

不必和這張名片相同。完成三行以上自訂介紹，加註解、修改並重跑，就達成主線任務。

## 學習單：離堂小挑戰

### 第 1 題：輸出順序與註解

```text
暱稱：小宇
興趣：畫畫
```

程式由上往下執行。以 `#` 開頭的整行是註解，其中的 `print()` 不會執行，因此隱藏技能不會出現。

### 第 2 題：修正漏掉的引號

```python
print("今天也要勇敢嘗試！")
```

文字結束後、右括號之前，缺少一個半形雙引號。補上後重新執行。

### 第 3 題：說明如何修改名片

```python
print("暱稱：星星")
print("興趣：打籃球")
print("口頭禪：再試一次！")
```

參考說明：「我改了三行引號中的文字；重新執行後，畫面會依序顯示新的暱稱、興趣與口頭禪。」

三行可執行、內容有自行修改、能說明修改與輸出的關係，就算完成；不限定文字。
