## 主線：順序與註解

在同一個程式格裡：

```python
print("穿上太空衣")
print("坐進太空船")
print("出發！")
```

依序輸出「穿上太空衣」「坐進太空船」「出發！」。交換第一行和第三行後，依序變成「出發！」「坐進太空船」「穿上太空衣」。

註解範例原本只顯示「太空任務開始」「準備出發！」。把第三行開頭的 `#` 和空格一起移除，讓 `print` 從最左邊開始後，會在中間多出「這句先不顯示」。

## 主線：修正漏引號

```python
print("今天也要勇敢嘗試！")
```

右括號前缺少結尾的半形雙引號。補上後重新執行該程式格，會顯示「今天也要勇敢嘗試！」。

## 主線作品：三行文字名片

```python
# 我的第一張程式名片
print("暱稱：星際飯糰")
print("興趣：聽音樂")
print("招牌技能：把問題拆小")
```

只要三行自選介紹、至少一行註解、修改後能重新執行，就符合基本作品要求。內容不必與範例相同，標題和框線也不是必須。

## Notebook／學習紀錄：快速自評

### 第 1 題：輸出順序與註解

```text
暱稱：小宇
興趣：畫畫
```

同一格內的程式由上往下執行。以 `#` 開頭的整行是註解，其中的 `print()` 不會執行，所以「隱藏技能」不會出現。

### 第 2 題：修正漏掉的引號

```python
print("今天也要勇敢嘗試！")
```

原因與前面的主線除錯任務相同，已完成者可以直接引用自己的修正版，不必重抄。

### 第 3 題：說明自己的修改

參考說明：「我把『聽音樂』改成『打籃球』；重新執行後，畫面會顯示『興趣：打籃球』。」

能指出自己真的修改過的一行，並說明新輸出即可。沒有唯一的角色名稱或內容答案。

一句反思也沒有標準答案，例如「今天我發現改完程式後，要再執行一次才會更新輸出」。
