# 🎮 第一堂闖關練習

[回學生講義](README.md) · [參考解答，做完再開](solutions/README.md)

每題另建一個 `.py` 檔；先預測、再執行。課內可挑第 3 題，課後選做一題、約 10 分鐘即可。

## 第 1 關｜任務廣播（基本）

請用三行 `print()`，讓畫面**依照下列順序**顯示：

```text
任務代號：星光
目的地：月球
準備出發！
```

完成條件：有三行輸出，文字與順序符合目標。

<details>
<summary>提示 1：我從哪裡開始？</summary>

每次要顯示一行文字，就寫一行 `print("內容")`。

</details>

<details>
<summary>提示 2：第一行怎麼寫？</summary>

```python
print("任務代號：星光")
```

</details>

## 第 2 關｜換我當導演（修改）

原始程式：

```python
# 原本的旅行計畫
print("交通工具：腳踏車")
print("目的地：圖書館")
```

把交通工具改成「太空船」、目的地改成「火星」，並把註解改成「我的太空旅行」。

預期輸出：

```text
交通工具：太空船
目的地：火星
```

完成條件：兩行輸出符合目標；註解已修改，但沒有出現在畫面。

<details>
<summary>提示：哪些字要保留？</summary>

保留 `print`、括號與外側引號，只改引號裡的文字。註解寫在字串外的 `#` 後面。

</details>

## 第 3 關｜除錯偵探（找錯）

以下三段都**故意寫錯**。請一段一段放進檔案，修好、執行，再做下一段。

片段 A，目標顯示「找到寶箱！」：

```text
print("找到寶箱！)
```

片段 B，目標顯示「獲得地圖」：

```text
print（"獲得地圖"）
```

片段 C，目標顯示「任務完成」：

```text
print("任務完成"
```

完成條件：三段都能執行，並用一句話說出每段改了什麼。錯誤示範保留在文字區塊，不是可直接執行的範例檔。

<details>
<summary>提示 1：檢查順序</summary>

先數引號是否成對，再找左右括號，最後看是否用了全形程式符號。

</details>

<details>
<summary>提示 2：各段的線索</summary>

A 少一個結尾引號；B 的兩個括號要換成半形；C 少右括號。

</details>

## 第 4 關｜四格文字故事（自由創作）

用四行 `print()` 寫一個有開頭、事件、轉折與結尾的故事，並在最前面加一行註解說明主題。

例如可以顯示：

```text
今天我搭上太空船。
導航突然說它想放假。
我拿出紙本地圖。
原來目的地就在隔壁！
```

完成條件：四行有順序的故事、一行不顯示的註解、成功執行。**內容可以完全自訂，沒有唯一答案。**

<details>
<summary>提示：還沒想到故事？</summary>

先用口頭完成四句：「今天我……」「突然……」「於是……」「最後……」，再把它們放進四行 `print()`。

</details>
