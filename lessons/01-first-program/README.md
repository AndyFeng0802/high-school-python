## 0–5 分｜準備出發

本週由上往下逐格完成。**同一個程式格內**的指令由上往下執行；Notebook 的不同格則依你按下執行的順序執行。只修改文字不會更新舊結果，要再執行一次。

## 5–13 分｜第一招：`print()` 讓電腦說話

先猜輸出，再執行：

```python
print("你好，Python！")
```

預期輸出：

```text
你好，Python！
```

| 程式的一部分 | 意思 |
| --- | --- |
| `print` | 請電腦把內容顯示出來；這裡不會使用紙張印表機 |
| `(` 與 `)` | 放入要顯示的內容，左右要配對 |
| `"你好，Python！"` | 一段文字，程式裡叫做「字串」 |
| 外側的一對 `"` | 標出文字的開始與結束，這對引號本身不會顯示 |

**立刻改一處：** 換成角色的開場白，例如「星際飯糰，準備出發！」，再執行一次。

程式的括號與引號使用半形 `()`、`"`；`print` 全部小寫。本週每行從最左邊開始。**引號裡的中文與中文標點可以照常使用。**

對照原始碼：[01_hello.py](examples/01_hello.py)

## 13–20 分｜第二招：誰先出場？

把三行放在**同一個程式格**，先猜順序再執行：

```python
print("穿上太空衣")
print("坐進太空船")
print("出發！")
```

預期依序顯示「穿上太空衣」「坐進太空船」「出發！」，每句各佔一行。

**交換實驗：** 交換第一行與第三行，先說出新順序，再執行。電腦會照你寫的順序做，不會自動把故事排合理。

對照原始碼：[02_launch.py](examples/02_launch.py)

## 20–25 分｜第三招：註解小紙條

```python
# 這是給讀程式的人看的提醒
print("太空任務開始")
# print("這句先不顯示")
print("準備出發！")
```

會顯示兩行：「太空任務開始」「準備出發！」。以 `#` 開頭的整行是註解，不會當成指令執行。

**開關實驗：** 刪掉第三行開頭的 `#` 和後面的空格，讓 `print` 從最左邊開始，再執行。觀察多出哪一句。

對照原始碼：[03_comments.py](examples/03_comments.py)。該檔案還有一個選看例子：`#` 放在引號裡就是普通文字，會顯示出來。

## 25–30 分｜除錯偵探：找回失蹤的引號

「除錯」就是找出問題並修好。下面這行**故意寫錯**，請在 Notebook 的修正版程式格寫出正確版本：

```text
print("今天也要勇敢嘗試！)
```

先找文字從哪裡開始、在哪裡結束，再檢查括號。卡住時看提示：**右括號前少了半形雙引號。** 修好後執行，確認它顯示「今天也要勇敢嘗試！」。

遇到其他錯誤時：

1. 看程式格下方的錯誤訊息與行號提示；提示位置不一定就是問題根源。
2. 檢查引號、括號、全形符號與 `print` 大小寫。
3. 一次改一處，再執行這一格。

先完成一個修錯就好。更多錯誤範例放在[選做闖關](exercises.md)。

## 30–42 分｜主線任務：我的文字名片

在 Notebook 的作品程式格，把三項介紹換成自己的角色設定：

```python
# 我的第一張程式名片
print("暱稱：星際飯糰")
print("興趣：聽音樂")
print("招牌技能：把問題拆小")
```

可以全部虛構。基本任務只有三件事：

- 至少三行自選介紹內容；標題或框線不算介紹內容。
- 一行 `#` 註解，說明作品主題。
- 修改後重新執行，確認結果符合設計。

完成後選做：加一行口頭禪，或使用 `print("====================")` 當框線。不需要完成所有加分題。

保留的 `.py` 骨架：[my_card.py](starter/my_card.py)。可把裡面的程式複製進程式格；本週不用另外建立 `.py` 檔。
