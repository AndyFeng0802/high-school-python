# 🚀 W01｜我的第一支程式：讓電腦說話

[課程首頁](../../README.md) · [操作指南](../../SETUP.md) · [下載 Notebook](W01_我的第一支程式.ipynb)

**高一零基礎｜50 分鐘｜Google Colab，JupyterLite 為備案**

今天用 Python 做一張角色的文字名片。整堂課只有 **一個示範、一次除錯、一個作品**，所有說明與操作都在同一份 Notebook。

## 從這裡開始

1. 開啟 [第一週 Colab](https://colab.research.google.com/drive/1LXPag1eda66wTrA1mrwClNdxuGomTEK2)，登入 Google 帳號。
2. 選 **檔案 → 在雲端硬碟中儲存複本**，在自己的副本操作。
3. 由上往下閱讀，點程式格左側 **▶** 或按 **Shift + Enter** 執行。

若不能使用 Colab，下載上方 `.ipynb`，上傳到 [JupyterLite](https://jupyter.org/try-jupyter/lab/) 再開啟；詳細步驟見 [操作指南](../../SETUP.md)。GitHub 頁面只供閱讀，不能直接執行程式。

## 50 分鐘路線

| 時間 | 任務 |
| --- | --- |
| 0–8 分 | 開啟教材，準備自己的副本 |
| 8–20 分 | 看一個示範，認識輸出、順序與註解；原格改一句 |
| 20–25 分 | 修好一次漏引號錯誤 |
| 25–42 分 | 修改名片骨架，完成三項角色介紹 |

## 本週只交一份 Notebook

作品包含三項自選介紹、一行 `#` 註解，能成功執行；另保留那一次修錯與一句反思即可。角色可以虛構，內容不用與範例相同。

下課前確認自己的 Colab 副本已儲存，再選 **檔案 → 下載 → 下載 .ipynb**。JupyterLite 則先儲存，再從左側檔案區右鍵下載。將備份帶到自己的雲端空間或隨身碟，避免學校電腦清除資料。
