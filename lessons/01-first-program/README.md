# 🚀 第一堂｜讓電腦說話：我的程式名片

[課程首頁](../../README.md) · [課前準備](../../SETUP.md) · [闖關練習](exercises.md) · [學習單](worksheet.md)

**時間：60 分鐘。起點：完全沒寫過程式，也沒關係。**

今天你是角色設計師。用幾行 Python，讓電腦介紹你創造的角色！題材可以是太空、運動、音樂或校園生活。

今天的完成線：自己執行程式、改出至少三行文字名片，說明一行程式，修好一個小錯誤。

## 0–5 分鐘｜先看今天的作品

```text
=== 我的程式名片 ===
暱稱：星際飯糰
興趣：聽音樂
招牌技能：把問題拆小
今天的任務：完成第一支程式
```

想一想：如果讓電腦介紹你設計的角色，你希望它說哪三句話？先口頭說出來即可。

寫程式，就是把想做的事寫成電腦能執行的指令。像寫一份清楚的操作步驟，順序與符號都會影響結果。今天先學一個指令就能完成作品。

## 5–15 分鐘｜第一招：`print()` 讓電腦說話

依[課前準備](../../SETUP.md)建立 `my_card.py`，輸入：

```python
print("你好，Python！")
```

先猜螢幕會出現什麼，再在編輯區按右鍵，選 **Run 'my_card'**。

預期輸出：

```text
你好，Python！
```

| 程式的一部分 | 可以怎麼理解 |
| --- | --- |
| `print` | 請電腦把內容顯示出來；這裡不會使用紙張印表機 |
| `(` 與 `)` | 放入要顯示的內容，左右要配對 |
| `"你好，Python！"` | 一段文字，程式裡稱為「字串」 |
| 外側的一對 `"` | 標出文字從哪裡開始、在哪裡結束；這對引號本身不會顯示 |

程式符號使用英文半形 `()` 與 `"`。**引號內的中文、逗號、驚嘆號可以照常使用。** `print` 要用小寫，這堂每行從最左邊開始寫。

🎯 **立刻改一處：** 把文字改成角色的開場白，例如「星際飯糰，準備出發！」，再執行一次。改程式後要重跑，輸出才會更新。

範例檔：[01_hello.py](examples/01_hello.py)

## 15–23 分鐘｜第二招：排好順序

在同一個檔案中換成下面三行：

```python
print("穿上太空衣")
print("坐進太空船")
print("出發！")
```

先猜 → 執行。預期輸出：

```text
穿上太空衣
坐進太空船
出發！
```

這些簡單指令會由上往下執行。這裡每次 `print()` 顯示一段文字，接著換到下一行。

🎯 **交換實驗：** 將第一行與第三行交換，先說出新順序，再執行。電腦會照指令順序做，不會替我們把故事排合理。

範例檔：[02_launch.py](examples/02_launch.py)

## 23–30 分鐘｜第三招：留一張註解便條

```python
# 這一行是給人看的說明
print("太空任務開始")
# print("這句先不顯示")
print("#1 任務：觀察月球")
```

預期輸出：

```text
太空任務開始
#1 任務：觀察月球
```

字串外的 `#` 會讓後面到該行結尾成為「註解」，Python 不把它當成要執行的指令。可以用來記錄想法，或暫時關掉一行。

**注意：** `"#1 任務：觀察月球"` 裡的 `#` 是文字，所以會顯示。

🎯 **開關實驗：** 刪掉第三行開頭的 `#` 和後面的空格，讓 `print` 從行首開始，再執行。輸出多了哪一句？

範例檔：[03_comments.py](examples/03_comments.py)

## 30–35 分鐘｜眼睛休息站

離開螢幕、喝水、看看遠處。順便想好角色的暱稱、興趣與招牌技能。可以全部虛構。

## 35–50 分鐘｜主線任務：設計我的程式名片

先在紙上或口頭規劃三行內容，再自己寫進 `my_card.py`。卡住時才看下面的骨架：

```python
# 我的第一張程式名片
print("=== 我的程式名片 ===")
print("暱稱：請改成你的角色暱稱")
print("興趣：請填一個興趣")
print("招牌技能：請填一項技能")
```

也可從 [my_card.py 練習骨架](starter/my_card.py) 開始；先將它另存或複製成自己的檔案。

**基本任務完成就算過關：**

- 至少顯示三行介紹內容，寫出自己設計的角色。
- 加上一行 `#` 註解，說明作品主題。
- 改動至少一處文字後，重新執行並確認結果。

完成基本任務後，再自由選擇一項加分挑戰：

- 加上 `====================` 作為名片外框。
- 用四行文字說一個小故事，包含開頭、事件、轉折、結尾。
- 加一句只有這個角色會說的口頭禪。

## 50–55 分鐘｜除錯偵探：找回失蹤的符號

「除錯」就是找出問題並修好它。錯誤訊息是線索，不是分數。

下面是**故意寫錯的片段，請分別修正後再執行**：

| 故意寫錯的程式 | 先找哪裡？ | 修好後 |
| --- | --- | --- |
| `print("任務開始！)` | 文字結束的引號不見了 | `print("任務開始！")` |
| `print("準備好了"` | 少了右括號 | `print("準備好了")` |
| `print（"出發！"）` | 括號用了全形 | `print("出發！")` |
| `Print("你好")` | 指令第一個字母變大寫 | `print("你好")` |

遇到錯誤時：

1. 看 Run 最下方的錯誤類型，例如 `SyntaxError` 表示語法有問題。
2. 找訊息中的 `line` 行號，回編輯區檢查該行與前一行。Python 指出的地方是線索，不一定是問題起點。
3. 先數引號，再看括號、半形符號與大小寫。
4. 一次改一處，再執行確認。

挑一個錯誤在自己的程式上體驗「出錯 → 修好」，再完成[闖關練習](exercises.md)中的除錯題。較長的 `.py` 檔若有語法錯誤，可能一行都還沒執行就停止；不要把這和正常執行順序混在一起。

## 55–60 分鐘｜展示你的第一支程式

向同學、老師或家人展示，說明：

- 我改了哪一段文字？
- 挑一行：它會讓電腦顯示什麼？
- 我修正了哪個錯誤？我是怎麼找到的？

完成[學習單](worksheet.md)第 1、2 題，第 3 題直接指著作品口頭說明；三行學習紀錄可課後補填。下次我們會讓程式「記住資料」，把名片升級成使用變數的角色資訊卡。
