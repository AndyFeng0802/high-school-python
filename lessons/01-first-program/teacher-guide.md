# W01 陪學指引｜我的第一支程式

[回第一週教材](README.md) · [Notebook](W01_我的第一支程式.ipynb) · [學習紀錄](worksheet.md) · [參考解答](solutions/README.md)

**對象：** 高一零基礎  
**模式：** 自主學習，每週 50 分鐘；教師或家長需要時提供協助  
**工具：** [線上 JupyterLite](https://jupyter.org/try-jupyter/lab/)  
**成果：** 一份已下載備份的 Notebook，內含三行以上文字名片、註解、簡短自評與反思。

本週只練習 `print()`、字串、同一程式格內的執行順序、整行 `#` 註解與簡單符號除錯。不提前加入變數、互動輸入、條件、迴圈或套件安裝。

## 陪學原則

學生可以依 Notebook 獨立完成。陪學者的任務是幫忙定位卡住的位置，讓學生自己修改與執行，而不是把每一段重新講授一次。

每段維持「先猜 → 執行 → 改一處 → 說明」的節奏。不要求同桌合作、全班展示或額外抄寫；口頭說給自己聽也算一次解釋。

## 開始前的準備

- 先用實際上課設備開啟 JupyterLite，確認能選到 Python 核心並執行 `print("準備好了！")`。
- 準備 [W01_我的第一支程式.ipynb](W01_我的第一支程式.ipynb) 的下載檔。學生在第一個 5 分鐘練習上傳與開啟；較久的網路或設備排除宜先處理。
- 確認學生知道電腦下載檔案的位置，並準備學校允許的個人雲端空間或隨身碟；最後 3 分鐘要下載並把備份帶走。
- 介面區分三個位置：左側檔案區、Notebook 的程式格、各程式格下方的輸出。
- 若核心名稱不同，選 Python 選項，例如 Python (Pyodide)。首次啟動可能需要等待載入。
- 使用虛構暱稱即可，不要求真實姓名或聯絡資料。本週不要求學生學 Git 或上傳個人作品到 GitHub。

## 本週最容易混淆的地方

### 指令與文字

用三句話就足夠：`print` 請電腦顯示內容；括號放內容；引號包住一段文字，這段文字叫做字串。引號內可使用中文與中文標點，程式的括號與引號使用半形。

不要把「程式符號用半形」說成「所有中文標點都不能使用」。例如 `print("你好！")` 中的中文驚嘆號沒有問題。

### Notebook 執行順序

必須區分：**同一個程式格內**，這些指令由上往下執行；**不同程式格之間**，依學生按下執行的先後決定。本週要求從上到下依序操作，是學習路線，不是 Notebook 自動保證的行為。

編輯後舊輸出仍可能留在下方。讓學生重跑目前這一格，確認新結果。範例各格彼此獨立，沒有依賴先前變數的狀況。

### 註解與練習答案

主線先使用整行 `#` 註解。Notebook 末段用註解格留下自評與反思；執行只有註解的格子而沒有輸出是正常的。

保留的 [03_comments.py](examples/03_comments.py) 有 `#` 在字串內的例子，只需在學生詢問時說明：「引號裡的 `#` 就是文字。」不必額外增加全班必學內容。

## 除錯時怎麼協助？

先問「你預期看到什麼？現在看到什麼？」再一次查一項。

| 現象 | 建議檢查 |
| --- | --- |
| 漏引號 | 文字前後是否都有半形雙引號 `"`？ |
| 漏括號 | 左右半形括號 `(`、`)` 是否成對？ |
| 看起來很像但無法執行 | 是否用了全形 `（ ）` 或彎引號 `“ ”`？ |
| `Print` 無法使用 | 是否寫成小寫 `print`？ |
| 取消註解後出現縮排錯誤 | 移除 `#` 後是否仍留下行首空格？ |
| 某句沒有出現 | 該行是否以 `#` 開頭？ |
| 改了文字卻仍看見舊內容 | 是否重新執行了正在編輯的格子？ |
| 一直等待，沒有結果 | 是否已選 Python 核心，並等待載入完成？ |

錯誤訊息的位置是線索，不保證剛好就是根源。主線只要修好一個漏引號範例即可，不要求背英文錯誤名稱。Notebook 內的錯誤題放在說明文字中，學生在下一個程式格寫修正版；下載後整份執行不會因教材故意的語法錯誤而中斷。

## 名片任務與合理減量

作品至少三行自選介紹內容，另有一行註解。標題、框線不算三項介紹；內容可以虛構。不要以裝飾、打字速度或內容是否和解答相同評分。

- **還需要協助：** 使用現成三行骨架，每次只改一行引號裡的文字，再執行。
- **進度較快：** 加第四行或框線，明確當作選做；不用增加新語法。
- **時間不足：** 省略所有選做與反思的額外提問；保留三行作品、一次修錯、一句說明與下載備份。
- **環境中斷：** 先紙上預測與規劃，再於可用設備實際執行；紙上作答不能替代執行驗證，完成紀錄應保留未完成項。
