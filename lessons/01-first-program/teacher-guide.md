# W01 陪學指引｜我的第一支程式

[回第一週](README.md) · [Notebook](W01_我的第一支程式.ipynb) · [學習紀錄](worksheet.md) · [參考解答](solutions/README.md)

**對象：高一零基礎｜時間：50 分鐘｜主要工具：Google Colab，JupyterLite 為備案**

本週只完成 **一個示範、一次修錯、一張文字名片**。概念限於 `print()`、文字字串、同一程式格內的順序與整行 `#` 註解，不加入變數、輸入、條件或迴圈。

## 課前準備

- 用教室設備開啟 [Colab 教材](https://colab.research.google.com/drive/1LXPag1eda66wTrA1mrwClNdxuGomTEK2)，確認能登入 Google 帳號、儲存副本並執行程式。
- 無法使用 Colab 時，備妥 `.ipynb` 檔，改用 [JupyterLite](https://jupyter.org/try-jupyter/lab/)。詳細操作見 [SETUP](../../SETUP.md)。
- 確認學生知道下載位置；學校電腦上的檔案需帶回個人雲端空間或隨身碟。

## 50 分鐘安排

| 時間 | 學生操作 | 完成證據 |
| --- | --- | --- |
| 0–8 分 | 開啟教材，儲存自己的副本 | 找到自己的 Notebook 與程式格 |
| 8–20 分 | 執行兩行示範，原格改一句再執行 | 看見新文字，知道註解不會顯示 |
| 20–25 分 | 補上一次漏掉的引號 | 修正版能執行 |
| 25–42 分 | 修改三行名片骨架，完成唯一作品 | 三項自選介紹與一行註解 |
| 42–50 分 | 記錄一句反思，儲存並下載 | 找到自己的 `.ipynb` 備份 |

## 陪學時只抓這幾件事

- 示範只用 Notebook 裡的那一格。請學生先猜輸出，再執行，最後直接改一句；不另抄一份。
- `print()` 顯示內容；引號包住文字，稱為字串。程式括號與引號用半形，引號裡的中文可以保留。
- 同一格內的指令由上往下執行；不同格依按下執行的順序執行。修改後要重跑，舊輸出才會更新。
- 以 `#` 開頭的整行是給人看的註解，不會顯示。先不增加取消註解或字串內 `#` 的變化題。
- 修錯只做一次：讓學生找出缺少的引號，再執行修正版；不用背英文錯誤名稱。
- 名片可用虛構角色，至少有暱稱、興趣、招牌技能三項介紹與一行註解。能說出自己改了哪一行即可，不要求裝飾或再做一張。

學生卡住時，先看他正在操作的那一格，一次協助一個問題。進度快者可檢查自己的作品；進度慢者可直接使用骨架。不要追加闖關題，也不要為了完成紙本學習紀錄而重做 Notebook 的內容。

## 最後確認

請學生指著自己的名片，簡單說明一處修改，再確認儲存與下載。

- **Colab：** 確認自己的 Drive 副本已儲存，選「檔案 → 下載 → 下載 .ipynb」。
- **JupyterLite：** 儲存後，在左側檔案區對 Notebook 按右鍵選「Download」。瀏覽器內儲存不等於已下載備份。

找到下載檔後，再放到學校允許的個人雲端空間或隨身碟。本週成果就是這一份 Notebook；學習紀錄僅供需要紙本的人使用。
