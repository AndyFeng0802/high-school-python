## 直接開始

**[在 Colab 開啟第二章](https://colab.research.google.com/github/AndyFeng0802/high-school-python/blob/main/lessons/02-variables/W02_%E8%AE%8A%E6%95%B8%E8%88%87%E8%A7%92%E8%89%B2%E8%A3%9C%E7%B5%A6%E7%AB%99.ipynb)**

也可[下載 Jupyter 筆記本](W02_變數與角色補給站.ipynb)，上傳至 [JupyterLite](https://jupyter.org/try-jupyter/lab/) 使用。開啟與備份方式見操作指南，課程最後兩分鐘只做結論。

## 完成成果

只完成一份 Notebook：在原有資料卡修改角色名字、金幣與裝備，計算買兩份補給的花費、餘額，並核對裝備交換前後的結果。

Notebook 共 18 格、6 個程式格，包含必要示範、一次名稱修錯及唯一作品。暫存交換用圖表理解，再執行 Python 的簡潔寫法；沒有另外一套闖關。
