# 高一上學期自主學習計畫書

## 1. 計畫名稱

Python初階程式設計自主學習

## 2. 內容說明

利用學校電腦教室，以線上Jupyter學習Python。每週50分鐘，共17次學習，循序練習基本語法、邏輯思考與除錯，並完成簡易程式作品。

| --- | --- |
| 第1週 | 認識Jupyter與程式輸出 |
| 第2週 | 變數與基本運算 |
| 第3週 | 輸入輸出與資料轉換 |
| 第4週 | 基本條件判斷 |
| 第5週 | 多條件判斷與應用 |
| 第6週 | 停課 |
| 第7週 | 條件判斷複習與除錯 |
| 第8週 | for迴圈與重複執行 |
| 第9週 | 累加與計數練習 |
| 第10週 | 停課 |
| 第11週 | while迴圈與停止條件 |
| 第12週 | 停課 |
| 第13週 | 迴圈複習與程式追蹤 |
| 第14週 | 字串處理與文字操作 |
| 第15週 | 串列與多筆資料處理 |
| 第16週 | 停課 |

## 4. 預期成果

1. 理解Python基本語法與程式設計概念。
2. 能運用變數、條件判斷及迴圈解決簡單問題。
3. 完成17次學習紀錄，保存程式練習與除錯過程。
4. 完成1件簡易程式作品，並說明功能與學習心得。
